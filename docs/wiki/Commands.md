# 命令

`/bbs_ai` 子命令：

| 命令 | 说明 |
|---|---|
| `generate storyboard <json>` | 从分镜 JSON 生成影片（可 undo） |
| `preview enter/exit/bake <mode>` | 预览模式与烘焙 |
| `ik mode <native\|blender>` | IK 模式 |
| `theme <classic\|blender\|mineimator>` | UI 主题 |
| `language <en_us\|zh_cn\|zh_tw>` | 界面语言 |
| `mods` | 查看 AI 对当前 mod 环境的理解 |
| `undo` / `redo` | 撤销 / 重做最近 AI 操作 |
| `version` | 版本信息 |
