# 版本兼容

同一份 bbs_ai 源码兼容上游 bbs-fs **2.5 / 2.6 / 2.7**：

- **编译期**：2.7-only API（TimelineEvents/FilmTools/ReplayActions/FormPoseEvents）隔离在独立类，2.5/2.6 树上不参与编译
- **运行期**：`BBSFSCompat` 解析 bbs 容器版本，`has27Api()` 守卫新体系注册（旧版本自动跳过）
- **基线**：2.7 分支基于 origin/dev-2.7 系列（2026-09-24 快照）
